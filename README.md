# Mishael's Portfolio Site

Personal portfolio built with Angular 20. It presents the main sections of the site as separate routes so visitors can move between the home page, about page, skills, education, projects, and contact form.

## Pages

- `/` Home
- `/about` About
- `/skills` Skills
- `/education` Education
- `/projects` Projects
- `/contact` Contact

## Requirements

- Node.js and npm
- Angular CLI 20.2.x

## Install

```bash
npm install
```

## Run

Start the development server with:

```bash
npm start
```

Open `http://localhost:4200/` in your browser.

## Build

```bash
npm run build
```

## Test

```bash
npm test
```

## Notes

The app uses Angular routing, so each page lives in its own component under `src/app/pages/`.
